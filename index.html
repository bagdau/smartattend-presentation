Архитектура

Как это работает

Три независимых потока на каждую камеру — дисплей никогда не ждёт вычислений.

📹
Камера
IP-камера аудитории 25 FPS
🎯
YOLOv8-Face
bbox + 5 ключевых точек лица
🧠
ArcFace R50
512-мерный эмбеддинг
⚡
Matching
Cosine similarity 2925 векторов
📊
Dashboard
React + WebSocket live
01
CaptureWorker Thread
Отдельный поток читает видео в FrameBuffer на полной скорости — MJPEG стрим не блокируется никогда.
02
InferenceWorker Thread
Второй поток берёт кадр, запускает GPU-инференс каждые N кадров и пишет результат в ResultBuffer.
03
Canvas rAF Overlay
Фронтенд рисует bbox через requestAnimationFrame — ноль React-ререндеров, плавные 30 FPS.
